# 月夜のタロット — Moonlit Tarot

星々があなたに語りかける夜、三枚のカードに過去・現在・未来を尋ねる、ブラウザ完結型のタロット占いアプリ。

## 特徴

- 大アルカナ22枚フルセット（日本語解釈付き）
- 3枚引き（過去・現在・未来）× 3テーマ（恋愛運・仕事運・総合運）
- 逆位置あり
- 星空アニメーション・カードフリップ演出・効果音
- アクセント色切替（ゴールド / シルバー / ローズ）
- 占い履歴をlocalStorageに保存

## 技術構成

- React 18（CDN）+ Babel Standalone
- バニラCSS
- ビルド不要・サーバー不要の単一HTMLアプリ

## ローカルで動かす

```sh
# 適当なローカルサーバーを起動
python3 -m http.server 8000
# → http://localhost:8000
```
